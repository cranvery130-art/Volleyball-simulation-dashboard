# video-watch (배구 경기 영상 보기)

영상을 Claude가 읽을 수 있는 두 가지로 바꿔요. **장면 사진**(언제 무엇이 화면에 있었나)과, 원하면 **소리 받아쓰기**예요.
원본은 moongiadventures-dev/moongi-video-skills 의 video-watch(MIT, 같은 폴더 `LICENSE`)이고, 배구 기록용으로 고쳤어요.

## 쓰는 범위

- **내 PC에 있는 경기 영상 파일만** 봐요. 유튜브 링크 내려받기는 약관 문제로 뺐어요(링크를 넣으면 멈춰요).
- 장면 사진과 모아보기는 `~/.claude/video-watch/` 아래(저장소 밖)에 저장돼요. 학생이 나온 사진이라 **저장소에 커밋하거나 외부 서비스에 올리지 않아요.**
- 기록에는 학생 이름 대신 **등번호·팀**만 써요.

## 실행

저장소 폴더에서:

```bash
# 경기 전체를 훑기 (장면 60장 이하, 간격 자동)
python .claude/skills/video-watch/scripts/watch.py "경기영상.mp4"

# 랠리 한 구간을 0.5초 간격으로 자세히
python .claude/skills/video-watch/scripts/watch.py "경기영상.mp4" --start 12:30 --end 12:50 --interval 0.5
```

결과(JSON으로 경로를 알려 줘요):

```
~/.claude/video-watch/<파일이름>[_시작-끝]/
  sheets/sheet_01.jpg …   # 장면 9장씩, 칸마다 [분:초]
  frames/…_12-30.5.jpg    # 파일 이름이 곧 시각
  meta.json               # 영상 길이, 구간, 간격
  transcript.md           # --whisper 를 줬을 때만
```

| 옵션 | 기본 | 언제 바꾸나 |
|---|---|---|
| `--start` / `--end` | 처음~끝 | 한 랠리·한 세트만 볼 때 (`95`, `1:35`, `0:01:35`) |
| `--interval` | 자동(1초 이상) | 랠리 안 동작을 볼 땐 `0.5`, 훑을 땐 비워 두기 |
| `--max-frames` | 60 | 넓은 구간을 촘촘히 볼 때 늘리기 |
| `--width` | 960 | 등번호가 작게 보이면 `1280` |
| `--whisper` | 끔 | 심판 콜·작전 지시 소리가 필요할 때 (faster-whisper 필요, PC 안에서 처리) |

필요한 것: `ffmpeg`·`ffprobe`, `pip install pillow`. `--whisper`는 `pip install faster-whisper`.

## 보는 순서

1. **전체를 훑어 랠리 구간 찾기.** 기본 간격으로 돌리고 모아보기(`sheets/`)를 차례로 봐요. 서브 준비 자세 → 공이 떨어지고 선수들이 멈춘 장면까지를 랠리 하나로 잡고 시각을 적어요.
2. **랠리마다 자세히.** 찾은 구간을 `--start/--end --interval 0.5`로 다시 돌려 서브·리시브·토스·공격·블로킹·득점 장면을 봐요.
3. **헷갈리는 장면만 낱장으로.** `frames/` 파일 이름이 시각이라 그 장면으로 바로 갈 수 있어요.

제목이나 짐작으로 기록하지 않아요. 화면에서 확인한 것만 적어요.

## 기록하는 법

랠리마다 한 줄로, 앱 빠른 기록과 같은 말로 적어요.

| 시각 | 세트 | 득점 팀 | 결과 | 상황(빠른 기록 버튼 이름) | 선수 번호 | 확신 |
|---|---|---|---|---|---|---|
| 12:31 | 1 | 우리 | 득점 | 공격 성공 | 7 | 높음 |

- **확신**은 높음·보통·낮음으로 적고, 낮음은 이유(공이 화면 밖, 등번호 가림 등)를 같이 적어요. 사람은 낮음 줄만 확인하면 돼요.
- 보이지 않은 것은 `확인 못 함`으로 남겨요. 지어내지 않아요.

## 정확도 시험 (TJ님 기록과 비교)

TJ님이 앱으로 기록한 같은 경기 내보내기 파일이 있으면, 랠리 시각(±3초)으로 짝을 지어 득점 팀·결과·선수 번호가 맞은 비율을 표로 보여 줘요. 틀린 줄은 장면 시각과 함께 적어 어디서 헷갈렸는지 보이게 해요.

## 앱의 AI 분석과의 관계

앱 안의 🎥 AI 분석(Gemini, 사용자 키)과는 별개예요. 이 스킬은 PC의 Claude Code에서 영상을 보는 방법이고, 앱 화면이나 동작은 바꾸지 않아요.
